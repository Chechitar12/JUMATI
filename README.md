# JUMATI v9
Aplicación educativa local para niños de 4 a 6 años.

## Ejecutar
```powershell
npm.cmd install
npm.cmd run dev
```
Abrir http://localhost:5173/

## Cambios v9
- Rompecabezas con escenas infantiles originales inspiradas en cuentos clásicos de dominio público.
- Imagen guía del tablero más clara y tenue.
- Cada pieza contiene elementos visuales; se reducen zonas lisas/blancas.
- Eliminado botón Guía: al tocar una pieza se ilumina automáticamente su destino.
- Eliminados controles visibles para pausar/desactivar sonido.
- Voz masculina juvenil para perfil Niño y femenina juvenil para perfil Niña, según voces disponibles en Windows/Chrome.
- Frases de conteo/suma/resta con singular, plural y género gramatical: una manzana, un perrito, cinco manzanas, etc.
- Series únicamente numéricas.
